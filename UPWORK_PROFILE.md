# Upwork Profile 文案包（AI 文本助手作品集）

> 用途：复制到 Upwork Profile（Overview 段）+ 作品集项目描述。
> 定位：学生开发者的第一个作品——证明能独立交付"从 0 到 1 的浏览器扩展产品"。

## 一、Profile Overview（英文，约 1500 字符）

```
I build practical browser extensions and automation tools with AI.

My latest project: "AI Text Assistant" — a Chrome extension that lets you
right-click any selected text on any webpage and instantly polish, translate,
summarize, or fix it with your own AI API key (BYOK, zero backend).

Why it matters:
• Zero backend — text goes directly from your browser to the API you
  configure. No middleman, no data collection, full privacy.
• Minimal permissions (contextMenus + storage only) — Chrome store review
  friendly, user trust first.
• Built with vanilla JS + Manifest V3 — no framework, no build step, easy to
  audit and extend.
• 38 automated tests (smoke / edge cases / real API end-to-end with semantic
  assertions) — I test what I ship.

I care about:
• Clean, testable code (TDD habits)
• Minimal permissions & privacy by design
• Small, focused products that solve one problem well
• Clear communication in English or Chinese

Currently a sophomore majoring in Electronic Information Engineering,
learning C and AI agent development. Looking for small, well-defined
projects where I can deliver fast and learn faster.

Skills: Chrome Extension · JavaScript · Automation · API Integration · Testing
```

## 二、作品集项目条目（Portfolio Item）

**Title:** AI Text Assistant — Chrome Extension (BYOK, AI right-click menu)

**Description:**
```
A Chrome extension (Manifest V3) that adds an AI-powered right-click menu
to any webpage: select text → polish / translate / summarize / fix with
custom templates. BYOK model — users bring their own API key, so there is
no backend, no data collection, no subscription.

Highlights:
- Vanilla JS + MV3, zero build step, minimal permissions
- OpenAI-compatible API support (DeepSeek / OpenAI / SiliconFlow / any)
- shadow DOM floating result with copy / replace-in-place
- 38/38 automated tests incl. real API end-to-end + semantic assertions
- Full store listing materials (EN/ZH descriptions, privacy policy, 5 screenshots)

Links: [GitHub repo] | [demo video]
```
