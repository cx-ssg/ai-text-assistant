AI 文本助手 - 隐私政策（Privacy Policy）

更新日期：2026-08-14

概述

本扩展（AI 文本助手 - 选中即用）不收集、不上传、不存储任何用户个人数据，也不包含任何分析、广告或追踪组件。

1. 文本处理

用户选中的文本仅在用户主动触发右键菜单操作时，发送至用户自己配置的 API 提供商（如 DeepSeek / OpenAI / SiliconFlow 等 OpenAI 兼容接口），用于完成润色、翻译、总结或纠错。扩展本身没有服务器，不经过任何第三方中转。

2. 本地存储

用户的 API Key、模型配置与自定义模板仅保存在浏览器本地（chrome.storage.local），不会同步到任何服务器。卸载扩展即删除全部本地数据。

3. 第三方

除用户主动配置的 API 提供商外，扩展不与任何其他第三方通信。

4. 权限

扩展仅使用两项权限：contextMenus（创建右键菜单）与 storage（本地保存配置）。扩展不读取、不记录用户的浏览历史或网页内容。

5. 数据删除

卸载扩展即删除全部本地数据；如需手动清除，在设置页删除 API Key 字段并保存即可。

联系方式：Chrome 网上应用店该产品页面留言。
